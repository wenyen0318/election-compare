# 選前看清楚｜2026 候選人政見比較網站

用同一套格式，比較 2026 地方選舉候選人的**經歷、主打政見、各議題政策、爭議與回應**。每一句都附來源；查不到候選人回應的質疑，網站會直接標示「尚未查找到該候選人回覆」。

- 🌐 網站：`https://<你的帳號>.github.io/<repo名稱>/`
- 🗺️ 目前收錄：臺北市長、新北市長、新竹市長、新竹縣長
- 🧩 議題：育兒、長照、交通、經濟、觀光、教育、都更、綠化、治安

## 頁面

| 頁面 | 內容 |
|---|---|
| `index.html` | 選擇地區 |
| `region.html?r=taipei` | 候選人的臉＋議題方塊 |
| `candidate.html?id=puma-shen` | 經歷、主打政見、各議題政見、爭議與回應 |
| `issue.html?r=taipei&i=renewal` | 同一議題，所有候選人並排比較（含來源與質疑回應） |

## 這個專案怎麼「繼續做下去」

規則寫在 [`AGENTS.md`](AGENTS.md)（`CLAUDE.md` 會自動載入它）。重點：

1. **內容只放在 `data/`**：新增縣市或候選人不用改任何 HTML/JS。
2. **固定的資料格式**：每位候選人一個 JSON，質疑一定有 `response` 欄位（查不到填 `null`）。
3. **來源登錄表**：所有引用先登錄在 `data/sources.json`。
4. **自動檢查**：`python3 scripts/validate.py` 會擋下沒來源、格式錯誤、漏寫回應欄位的資料。
5. **斜線指令**：在 Claude Code 輸入 `/add-region 新竹縣`，AI 就會照規則新增整個縣市。
