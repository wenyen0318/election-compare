資料原則

📑 每句話都有出處政見、經歷、質疑與回應都連結到原始報導或官方資料；沒有來源的經歷會標示「待核對來源」。
⚖️ 同一套格式對待每個人每位候選人用相同欄位呈現；排序依姓名筆畫（中選會號次公布後改依號次）。候選人頁使用其競選主視覺色，查不到時才暫用政黨色並標明。
💬 質疑一定配回應對手或民眾的質疑旁邊，放上候選人自己的回應；找不到時標註「尚未查找到該候選人回覆」，而不是替他回答。
🚫 不做評分、不下結論本站只整理「誰說了什麼」，不判斷政見好壞，也不預測選情。
本站為「生成式AI」課程作業，資料整理自公開新聞報導，每筆內容皆附來源連結；標示「待核對來源」者請以中選會選舉公報為準。
本站不支持任何候選人或政黨。發現錯誤或有更完整的回應資料，歡迎在 GitHub 提出 Issue。資料更新至 2026-11-16。
